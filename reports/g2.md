## 设计偏差记录（相对 brief）

1. **导出形状：plain `{ id, setup }`，不是 `Plugin.define(...)` 包装。** 三个依据。(a) jscpd 零新重复门拦下了照抄 skill-tracker 的 createRequire 解析块（31 行克隆），brief 的纪律条（共享定义放一处）与该门方向一致。(b) V2 文档契约是"one default export containing a unique plugin id and a setup function"，herdr 的 `herdr-agent-state.js` 正以此形状在本机生产环境作为自动发现裸文件插件运行。(c) 真机验证：live 门服务日志 `loading plugin .../plugins/safety-gate.js` 无错，且 deny 功能实测成立。skill-tracker 自己的 identity-define 兜底在本就无 `@opencode/plugin` 的宿主上同样坍缩到该形状。
2. **live 门需要一步隔离，方法在 run-m1.sh 之上多一层。** 第一次跑（完整 devkit 安装的一次性根）模型完全没走 bash 面：它读了原生披露的 safety 技能，改走 MCP 的 `huaweicloud_hook_check_command` 与 `huaweicloud_run_readonly_command --help`，再 plan 并尝试表单确认（非交互下取消）。技能层先于 hook 层起效，这是分层正确的证据，但它把适配器完全遮住了。G1 探针没有这个问题，因为它的根里根本没有 devkit 披露面。处置：保留真实 installer 的部署产物（`plugins/safety-gate.js` + `huaweicloud-plugins/` payload 原样在盘），仅剥掉披露面（mcp 条目、原生技能、commands、permission 规则），复跑两例。拒绝例的 deny 原因逐字回传模型，良性例正常执行。两次运行的日志都保留在 `/tmp/opencode/hookgate-g2-live/logs/`，第一场作为"全栈叠加 + 良性 echo 不受干扰"的加成数据点。
3. **干净 deny 通道的实测比 G1 测的更丰富。** G1-M2 测的是抛异常路径（`type:"unknown"`）。本次干净路径（`effect="deny"` + `message`）实测回传 `{"error":{"type":"permission.rejected","message":"Huawei Cloud safety hook blocked this action: ..."},"content":[]}`，message 逐字，宿主不崩、run exit 0。文档语义被真机确认。
4. **结构 guard 未误伤，但扫描表显式扩了。** guard 实际在 `test/structure-runtime.test.ts`（brief 写的 `test/structure.test.ts` 不含该 guard），deny 模式是 skill-load 分类标记（`skill:retrieve|isHuaweiCloudSkill|extractSkillName`），新文件不命中任何一条，无需改规则。仍把 `safety-gate.js` 加进扫描文件表：server-data doctrine 对新 hook 文件显式覆盖，这是 roster 扩展不是规则修订，PR 里说明如本条。
5. **256KiB 长度帽确认在 `classifyTextCommand` 内部，未在适配器补第二层。** `classify-text.ts` 的 262_144 字节帽实测兜住（测试钉 over-cap deny），适配器免费继承，符合 brief 的"确认后免费继承"预期。
6. **无 src fallback（与 `.mjs` 孪生的刻意分歧）。** `.mjs` 为裸 checkout 保留 `src/safety-policy.ts` 回退；适配器只经 installer 部署，而 `copyServerPayload` 对缺 `dist/` 直接抛错拒绝部署，部署态永远有 dist。适配器注释记录该理由。
7. **版本探针语义确认。** floor 是 2.0 major（1.x 无 evaluate hook 且 action 名是 `bash`）；探针复用 `opencode-config.ts` 的进程内单次缓存，与 seam/ask 两 gate 共享一次 spawn。override `HUAWEICLOUD_OPENCODE_SAFETY_GATE=on|off` 未设时跑自然探针，未知极性是 skip 不是 fail（doctor SKIP、安装 INFO + drift heal）。
