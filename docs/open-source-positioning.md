# Open Source Positioning

HuaweiCloud DevKit should make developers more effective with Huawei Cloud open capabilities.

The project should optimize for:

- less agent context
- fewer documentation round trips
- clearer capability selection
- safer local execution
- faster troubleshooting
- reusable guidance for multiple agent clients

The project should avoid:

- copying every Huawei Cloud document
- encoding every service as a large built-in skill
- making live write operations too easy
- asking users to paste secrets
- treating Terraform as the only production path in V1
