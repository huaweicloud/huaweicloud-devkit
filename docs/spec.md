## Objective

修复每日测试（2026-10-07，被测版本 1.1.8-next.1）发现的 2 项 P1 缺陷：
1. JSON 凭据脱敏不完整（D2-4/D4-27）— `redactString()` 未识别 JSON `"key":"value"` 结构中的短键（ak/sk/token），且 `(AK|SK)` 正则缺少 `/i` 标志导致小写 `ak=`/`sk=` 漏脱敏。
