# Sandbox Resource Pool — 定稿口径参数（#1071）

> 资源池上线评审五问定稿答复的落码参考。配额/生命周期语义见 SKILL.md 的
> [Resource Pool Selection] 与 [Sandbox Lifecycle & Retention] 章节；本文是参数速查表。

## 两类沙箱

| 维度     | 非持久化 (ephemeral)          | 持久化 (persistent)                          |
| -------- | ----------------------------- | -------------------------------------------- |
| 定位     | 预览/试用/一次性任务/敏感即焚 | 开发工作台/带数据库项目/跨日评审展示         |
| 生命周期 | 固定 3h（CreateTime 判定）    | 1h 闲置关机 + 三信号活性                     |
| 存储     | 无持久盘                      | 挂 EVS 32G                                   |
| 配额     | 每用户 1 个（同类复用）       | 每用户 1 个（同类复用；可与 1 个非持久并存） |

## 申请（资源池容量规划口径）

| 资源               | 容量        |
| ------------------ | ----------- |
| 持久化 2U4G 规格   | 300 实例    |
| 持久化 4U8G 规格   | 200 实例    |
| 非持久化 2U4G 规格 | 1000 实例   |
| overlayer          | 5 GB / 实例 |
| EVS（持久化挂盘）  | 300 TB 总量 |

## 配额与超限语义（写入工具描述层）

- 每用户每类型 1 个实例；可同时持有 1 非持久化 + 1 持久化；同类请求复用现有实例。
- 超限响应：**HTTP 429 + `Retry-After` 头 + 错误码**。
- 错误码必须区分两类失败：
  - **配额超限（quota exceeded）** — 用户侧持有已达上限；按 `Retry-After` 等待或结束占用该类型沙箱的任务后再试。
  - **容量不足（capacity insufficient）** — 资源池侧无可用容量；稍后重试或改选另一类型。

## 烧核播报口径

沙箱消耗核时（烧核）时向用户播报：核时来源于**平台赠送 + 活动赚取**（非直接计费口径）。

## 平台侧关键依赖（G 清单，非 devkit 交付）

- G1 闲置删除策略配置（资源组，驱动 14 天保留期回收）
- G2 活性三信号（connect / 进程 / 预览流量）
- G3 状态查询 API
- G4 销户开机处置
- G5 销户实例回收
